# LNCN Groenteprijzen Data Publicatie

## ⚠️ Belangrijke Juridische Waarschuwing

Dit project onderzoekt de mogelijkheid om groenteprijzen data van LNCN te publiceren. **De publicatierechten zijn nog niet geverifieerd**.

**STATUS**: 🔴 **NIET GEVERIFIEERD** - Publicatie is momenteel NIET toegestaan tot schriftelijke toestemming van LNCN is verkregen.

## Overzicht

Dit repository bevat documentatie en (toekomstige) tools voor het beheren en publiceren van groenteprijzen data, mits de juiste licenties en toestemmingen zijn verkregen.

## Juridische Overwegingen

### Waarom is dit belangrijk?

Data verkregen via een betaald abonnement is vaak beschermd door:
- Contractuele voorwaarden (Terms of Service)
- Intellectueel eigendomsrechten
- EU Database Directive rechten
- Sui generis database rechten

### Risico's van ongeautoriseerde publicatie:
- ❌ Contractbreuk
- ❌ Juridische claims
- ❌ Beëindiging van abonnement
- ❌ Financiële schadevergoeding
- ❌ Reputatieschade

## Alternatieve Opties

Als directe publicatie niet mogelijk is:

1. **Afgeleide Data**: Publiceer alleen statistieken en analyses
2. **Intern Gebruik**: Gebruik data alleen intern
3. **Alternatieve Bronnen**: Zoek open data alternatieven voor groenteprijzen
4. **Custom Licentie**: Vraag LNCN om speciale open data licentie

## Mogelijke Open Data Alternatieven

Als LNCN publicatie niet toestaat, overweeg deze bronnen:
- CBS (Centraal Bureau voor de Statistiek)
- EU Agricultural Markets Observatory
- FAO Price Database
- Nationale landbouw open data portals
